# FrontlineBrowse

A Frontline Church branded Chromium browser for Apple Silicon Macs running macOS 13 or later.

[Download the latest preview](https://github.com/mhpullen/frontlinebrowse-releases/releases/latest)

Open the disk image and drag FrontlineBrowse to Applications. Quit an existing copy before replacing it. Older builds need one manual installation to gain the signed updater. Browser profiles are kept separately from the app.

## Updates

Use FrontlineBrowse → Check for Updates, or frontline://settings/help. Automatic update checks run hourly while the browser is open. The update feed and download signatures are verified before installation.

This repository distributes owner-built releases. It does not automatically build new Chromium security patches.

## Preview distribution status

Apple Developer ID signing and notarization are pending. Current preview builds have a local ad hoc signature; employee production rollout is not complete. Do not disable macOS security protections to install them.

Chromium and third-party credits are preserved in the browser. Engine source changes and build materials are maintained by the release owner.
